# Activity 5 – Step 2: With examples (few-shot)

**Chatbot / model: Gemini 3.6 Flash**

## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
For example:
* [BVA] 7 characters, one below the minimum ("Secret1") → rejected
* [EP] no digit ("SecretPass") → rejected
```

## Response

* [BVA] 7 characters, one below the minimum ("Secret1") → rejected
* [BVA] 8 characters, exact minimum ("Secret12") → accepted
* [BVA] 20 characters, exact maximum ("SecretPassword123456") → accepted
* [BVA] 21 characters, one above the maximum ("SecretPassword1234567") → rejected
* [EP] no uppercase letter ("secret123") → rejected
* [EP] no digit ("SecretPass") → rejected
