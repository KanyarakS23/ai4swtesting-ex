# Activity 5 – Step 1: Without examples (zero-shot)

**Chatbot / model: Gemini 3.6 Flash**

## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
```

## Response

Since your team's specific test idea format wasn't provided, here are 6 structured test ideas formatted using standard testing conventions (Focus / Scenario / Test Inputs / Expected Result).

### Test Ideas: Password Validation Rules

1. **Verify Minimum Boundary Length (8 Characters)**
* **Focus:** Boundary Value Analysis (Lower Limit)
* **Test Input:** `Ab12345` (7 chars - Fail), `Ab123456` (8 chars - Pass)
* **Expected Result:** Reject 7-character password with a length validation error; accept valid 8-character password.


2. **Verify Maximum Boundary Length (20 Characters)**
* **Focus:** Boundary Value Analysis (Upper Limit)
* **Test Input:** `Ab123456789012345678` (20 chars - Pass), `Ab1234567890123456789` (21 chars - Fail)
* **Expected Result:** Accept valid 20-character password; reject 21-character password with a length validation error.


3. **Verify Digit Requirement Enforcement**
* **Focus:** Character Set Validation (Missing Digit)
* **Test Input:** `PasswordUpper` (13 chars, uppercase included, 0 digits)
* **Expected Result:** Reject password and display an error stating at least one digit is required.


4. **Verify Uppercase Letter Requirement Enforcement**
* **Focus:** Character Set Validation (Missing Uppercase)
* **Test Input:** `password123` (11 chars, digit included, 0 uppercase)
* **Expected Result:** Reject password and display an error stating at least one uppercase letter is required.


5. **Verify Support for Special Characters and Spaces**
* **Focus:** Equivalence Partitioning / Allowed Character Sets
* **Test Input:** `Pass 1234!@#$` (13 chars, uppercase, digit, space, symbols)
* **Expected Result:** Successfully accept the password assuming special characters/spaces are not explicitly restricted.


6. **Verify Handling of Whitespace-Only / Empty Inputs**
* **Focus:** Edge Case / Input Sanitization
* **Test Input:** `        ` (8 spaces), `        A1` (8 leading spaces + A1)
* **Expected Result:** Reject empty/blank input; ensure trimming policies (if any) do not bypass minimum length or character rules.
