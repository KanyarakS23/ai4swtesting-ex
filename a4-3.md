# Activity 4 – Step 3: Give the LLM a way out

**Chatbot / model: Gemini 3.6 Flash** 

## Prompt

```text
You will be given a list of foods delimited by three hashes. Extract all the fruits and write them out as a list.
If there are no fruits in the list, simply write "No fruits found".
If you are not sure whether an item is a fruit, do not guess. List it under "Unsure" with a one-line reason.
###
bread, cheese, carrot, rice, chicken, tomato, strawberry yogurt, fruit cake
###
```

## Response

```python
foods = [
    "bread",
    "cheese",
    "carrot",
    "rice",
    "chicken",
    "tomato",
    "strawberry yogurt",
    "fruit cake",
]

# "tomato" is botanically a fruit, though culinary usage varies.
# "strawberry yogurt" and "fruit cake" contain fruit, but are processed dishes rather than fruits themselves.

unsure = {
    "tomato": "Botanically a fruit, but culinarily classified and used as a vegetable.",
    "strawberry yogurt": "Contains fruit as an ingredient, but is primarily a dairy product.",
    "fruit cake": "Contains dried/candied fruits, but is a baked dessert overall.",
}

print("No fruits found\n")
print("Unsure:")
for item, reason in unsure.items():
    print(f"- {item}: {reason}")
```
